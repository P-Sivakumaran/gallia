## 2. Portal Verification Details

### Juventus IR (Borsa Italiana / 1Info SDIR)
- **Primary Source:** Juventus Investor Relations Price Sensitive Press Releases & Computershare 1Info SDIR.
- **Announcement Frequency:** Material definitive transfers, loans with options/obligations, terminations, and contract extensions.
- **Data Points Disclosed:**
  - Consideration (fee in € million), payment instalments (number of financial years).
  - Ancillary costs and performance-related bonuses.
  - Capital gain / loss and net book value impact.
  - Contract expiration date (employment contract duration).
- **Robots & Access Terms:**
  - `juventus.com/robots.txt` checked 2026-11-26: Disallows `/_libraries/*`, `/en/automatedtest/*`, `/en/catalogue/*`, `/en/mobileapp/*`, `/en/opta_test/*`, `/en/thirdparties/*`.
  - Price-sensitive press releases under `/en/club/investor-relations/` are permitted.
  - Access delay: minimum 2 seconds per document.

### KAP Turkey (PDP / Kamuyu Aydınlatma Platformu)
- **Clubs:** Galatasaray SK (`GSRAY`), Fenerbahçe SK (`FENER`), Beşiktaş JK (`BJKAS`), Trabzonspor (`TSPOR`).
- **Data Points Disclosed:** Comprehensive player wages, transfer fee, agent commissions, and contract dates.
- **Verification Result:** Automated requests fail with HTTP 500 error code `5198321-PPE1` generated by Turkish capital markets cloud security.
- **Policy Compliance:** **STOP AND REPORT.** Do NOT scrape or bypass KAP WAF. Ingestion requires official licensed MKK data vendor API or manual data entry for Turkish transfers.

### SEC EDGAR (Manchester United plc - Form 6-K / Form 20-F)
- **Primary Source:** SEC EDGAR REST API `https://data.sec.gov/submissions/CIK0001549107.json`.
- **Policy Compliance:**
  - Fair Access Limit: maximum 10 requests per second.
  - Mandatory User-Agent header containing contact email.
  - Approved by Siva (Post `zl0foo`): User-Agent format `GalliaTransferBot/1.0 (+https://gallia.club; AdminContact@<sample company domain>.com)`.

```
   └── Club Parser (e.g. juventus.ts)
          │
          ▼
   [ExtractedTransferFact]
          │

          │       │
          │       ├──> recordTransfer(source: 'filing', confidence: 0.95, licence: 'primary-disclosure')
          │       │       └── creates/upgrades Transfer + SourcedFact(field: 'fee')
          │       │
          │       └──> recordContract(source: 'filing', confidence: 0.95)
          │               └── updates ContractFact + SourcedFact(field: 'contract')
          │
          └──> [DB Match: Unmatched Player or Club]
                  │
                  └──> recordUnmatchedFiling()
                          └── SourcedFact(entityType: 'UNMATCHED_TRANSFER', applied: false)
                                  [Admin Review Queue]
```
